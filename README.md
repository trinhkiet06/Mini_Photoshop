# Mini_Photoshop
Mini PhotoShop - Ứng dụng chỉnh sửa ảnh cơ bản được phát triển như đồ án nhóm, hỗ trợ các chức năng như cắt ảnh, xoay ảnh, điều chỉnh độ sáng/tương phản, áp dụng bộ lọc (filter) và các công cụ chỉnh sửa ảnh thông dụng khác. Dự án được xây dựng nhằm mục đích học tập và thực hành làm việc nhóm
